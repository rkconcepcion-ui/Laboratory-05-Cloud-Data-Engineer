# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This mission focused on deploying MinIO, an S3-compatible object storage server, using Docker. The activity demonstrated how object storage can be deployed and managed in a containerized environment.

## Objectives

* Deploy a MinIO object storage server using Docker.
* Access the MinIO Web Console.
* Create an object storage bucket.
* Upload a sample file to the bucket.
* Document the deployment and configuration process.

## Tools Used

* KillerCoda Ubuntu Playground
* Docker
* MinIO
* MinIO Web Console
* Linux Command Line
* GitHub

## Skills Learned

Through this mission, I learned how to deploy a storage server using Docker, configure environment variables, map container ports, verify a running container, access a web-based storage console, create a bucket, and upload objects. I also gained more experience using Linux commands to manage and verify containerized services.
